## الهدف وحدود التنفيذ
- الحفاظ على شاشة التسجيل الأصلية التي اعتمدها المالك، وعدم إنشاء داشبورد بديل أو تغيير تصميم أقسام المنصة الداخلية قبل الموافقة مرحلةً مرحلة.
- ربط التسجيل وتأكيد البريد وتسجيل الدخول بلوحة الطالب **الحقيقية** الحالية `app/platform.tsx` عند المسار `/`.
- رفع العمل إلى GitHub **Draft PR #20** وعرض معاينة Vercel قبل الدمج والنشر الإنتاجي.

## ما تم فحصه وإصلاحه
1. `app/login/page.tsx`: يحيل إلى واجهة `public/farmakon-auth.html` الأصلية؛ لا توجد لوحة وهمية.
2. `app/page.tsx`: SSR يتحقق من جلسة Supabase الحقيقية ومن `email_confirmed_at` قبل عرض `app/platform.tsx`. غير الموثق يذهب إلى `/login`.
3. `app/api/auth/route.ts`: إنشاء حساب مع بيانات المرحلة/الجامعة/المحافظة؛ التحقق من OTP التسجيل؛ طلب الاستعادة وتأكيد `type:recovery` وتعيين كلمة المرور ثم الخروج. مراجعة Preview `FARMAKON_PREVIEW_READ_ONLY=1` تسمح فقط بـ`login`/`logout` في Auth، حتى لا ترسل طلبات تسجيل/استعادة إلى مشروع Supabase الإنتاجي مع بقاء قالب البريد القديم.
4. `app/api/platform/route.ts`: لا ينفذ عملية إنشاء/تحديث سجل العضو في GET في وضع المعاينة للقراءة فقط؛ جميع POST ترد `403` حين العلم مفعّل.
5. `app/api/media/route.ts`: يُمنع POST/رفع الملفات في وضع المعاينة للقراءة فقط.
6. **لم نغيّر** `app/platform.tsx` ولا هوية تصميمه، ولم نعدّل `app/globals.css`، ولم ندمج المستودع الرئيسي.
7. بقية تصميم صفحة التسجيل، خانات الست أرقام الفعلية، القوائم، العربية/الإنجليزية، الضوء/الظلام، إعادة الإرسال، وواجهات استعادة كلمة المرور محفوظة.
