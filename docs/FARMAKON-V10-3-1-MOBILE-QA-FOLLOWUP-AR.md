# Farmakon V10.3.1 — QA & Accessibility Follow-up (03-11-2026)

## النطاق
فرع مراجعة مستقل فوق PR #24. لا تعديل على main أو تسجيل الدخول أو لوحة المالك أو بيانات الإنتاج. تبقى المعاينة التجريبية توضيحية فقط، والتبديل اللغوي ضمن مرحلة الإعدادات.

## التغييرات المنفذة
1. **البحث العام:** استخدام نفس تطبيع الكلمات العربية المستعمل في بحث الكورسات، مع تجاهل الحركات، وتوحيد الهمزات/التاء المربوطة ودعم الكلمات المتعددة بترتيب مختلف. ينطبق على أسماء الكورسات والمكتبة المسموح بعرضها في مربع البحث العام.
2. **العدادات والمدة:** استبعاد المحاضرات المقفلة من الإحصائيات المعروضة المرتبطة بالمحاضرات المنشورة المتاحة، بحيث يطابق مجموع المحاضرات والمدة أساس حساب التقدم.
3. **توضيح التقدم للقارئ الآلي:** لا نعلن عن قيمة تقدم 0% في حالة عدم وجود محاضرات منشورة متاحة؛ نستخدم وصفاً صريحاً بدلاً من قيمة موهومة.
4. **التنقل:** عدم إظهار مؤشر بصري زائف على تبويب «الرئيسية» حين تكون شاشة/نافذة أخرى مفعلة ولا يوجد تبويب نشط.
5. **واجهة الهاتف:** محاذاة زر فتح الكورس لأسفل البطاقات، حماية وصف المحتوى الطويل، تسمية التصنيف، إظهار عنوان «كمّل من وين وقفت» بسطرين، وإظهار التركيز على البحث.
6. **اختبارات انحدار:** حالات جديدة للبحث المتعدد والأرقام المتسقة والتنقل؛ تبقى مجموعات الاختبارات الأصلية مفعلة عبر prebuild.

## بوابات القبول قبل الدمج
- تشغيل npm run prebuild / npm run build / npm run typecheck في بيئة CI مع الاطلاع على النتائج الفعلية. **لا تعتبر هذه الفحوص ناجحة إلا إذا أكدت تقارير CI ذلك.**
- اختبار عرض 320 / 360 / 390 / 430 / 768 / 1366 على الهاتف والتابلت وسطح المكتب، بما فيه فتح لوحة المفاتيح والقائمة والفلاتر ونهاية الصفحة.
- اختبار الوصول: قارئ الشاشة، التنقل بلوحة المفاتيح، الإغلاق بالـ Escape، حجم مناطق الضغط والتباين.
- اختبار E2E ضد قاعدة Staging معزولة بعد معالجة مشكلة DATABASE_URL المنصوص عليها في تقارير V10.2؛ لا تجربة على قاعدة الإنتاج أو على اشتراكات/بيانات الطلاب الحقيقية.
